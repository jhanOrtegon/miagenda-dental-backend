# MiAgenda Dental (Backend)

Este es el backend del SaaS **MiAgenda Dental**, desarrollado con **NestJS** y **PostgreSQL**, listo para ser desplegado mediante Docker.

## 🚀 Requisitos

- Docker y Docker Compose
- Node.js 18+ (solo si se ejecuta localmente sin contenedores)

## 📦 Instalación con Docker

```bash
# Clona este repositorio o descarga el .zip
cd miagenda-dental-backend

# Inicia los servicios
docker-compose up --build
```
